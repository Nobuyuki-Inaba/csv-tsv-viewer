# CSV/TSV Viewer

[English](https://github.com/Nobuyuki-Inaba/csv-tsv-viewer/blob/main/README.md) | 日本語

CSV・TSV データを VS Code 上で表として表示します。エディタで選択したテキスト、クリップボード、
エクスプローラーのファイルの3つが入口です。すべてローカルで動作し、外部通信は一切行いません。
ランタイム依存パッケージもありません。

![エクスプローラーの右クリックから TSV ファイルを表として表示](https://raw.githubusercontent.com/Nobuyuki-Inaba/csv-tsv-viewer/main/images/screenshot.png)

## 機能

### 選択テキストのプレビュー

任意のエディタで CSV・TSV データを選択して右クリックし、**CSV/TSV: 選択範囲を表として表示** を
選びます。区切り文字は既定で選択内容から自動判定します（カンマ・タブ・セミコロン・パイプ）。
設定で固定することもできます。

スペース区切りにも対応しています。ツールバーで **スペース** を選ぶか、
`csvTsvViewer.selectionDelimiter` を `space` に設定してください。連続するスペースは 1 つの区切りと
して扱い、行頭のインデントは無視するので、`ps` や `df` の出力、貼り付けた桁揃えのレポートなども
そのまま表になります。自動判定でスペースが選ばれるのは、他の区切り文字がどれも当てはまらず、かつ
サンプルした全行が同じ列数に分かれる場合だけです（通常の文章を表と誤認しないため）。

**TAB / 連続スペース** は、タブが失われた TSV のためのモードです。チャットの回答や描画済みの
ドキュメントからコピーしたテキストは、タブがスペースに展開された状態で届くことが多く、しかも
タブストップ揃えのため展開後の個数は列ごとにばらつきます。このモードはタブ、または 2 個以上の
連続スペースで区切るので、スペース 1 個はセルの中身として残り、`New York  8` は 3 列ではなく
2 列として読めます。自動判定では `space` より優先され、判定条件は同じ（複数行あり、全行が同じ
列数に分かれること）です。

このメニュー項目はテキストを選択しているときだけ表示されます。プレビューを開いている間は選択に
追従するので、別の範囲を選び直すと表が描き直されます。

### クリップボードのプレビュー

コマンドパレットから **CSV/TSV: クリップボードを表として表示** を実行すると、直前にコピーした
区切りテキストをそのまま表にできます。クエリ結果、ログの一部、表計算ソフトからコピーした範囲
などを、ファイルに保存せず確認できます。

これはコマンドパレット専用です。クリップボードは右クリックできる対象ではないため、コンテキスト
メニューには追加していません。また、何を表示しようとしているか事前に見えない入口なので、区切り
文字も改行も含まないテキストは 1×1 の無意味な表として開かず、メッセージで拒否します。

### 表の操作

3つの入口はすべて同じ表ビューを共有します。

- **ページ表示** — 既定で1ページ 200 行（`csvTsvViewer.pageSize`）。先頭・前・次・末尾のボタンと、
  `1–200 of 12,000` 形式の行範囲をフッタに表示します。
- ヘッダ行と行番号列は固定表示です。行番号は元ファイルの行番号なので、絞り込み・ソート・ページ
  移動をしても意味が変わりません。
- ヘッダをクリックでソート（昇順 → 降順 → 元の順）。数値列は数値として比較し、空セルは常に最後に
  並びます。**ソートと絞り込みはファイル全体に効きます**（現在ページ内だけではありません）。
- 絞り込みボックスは全列を大文字小文字を無視して部分一致で検索します。
- **縦横変換** — 行と列を入れ替えます。列数の多い 1 件のレコードを縦に読みたいときに便利です。
  もう一度押すと元に戻ります。ソートと絞り込みは、入れ替え前の向きを指すものなので解除されます。
- 列の境界をドラッグすると列幅を自由に変えられます。つまみは表の高さいっぱいにあるので、ヘッダ
  だけでなくデータ行のどこからでも掴めます。ダブルクリックすると自動計算の幅に戻ります。変更した
  幅はソート・絞り込み・ページ移動をまたいで保持され、データの読み込み直しや縦横変換でリセット
  されます。手動で決めた幅は **折り返し** の均等幅よりも優先され、ドラッグした列だけが変わります。
- **折り返し** — 1 つのセルが極端に長く、横スクロールしないと何も読めないデータ向けです。列幅を
  すべて同じ幅に揃えて 3 行分の高さで折り返し、どのセルも同じ幅・同じ高さにします。3 行に収まら
  ない分は切り捨てますが、マウスを重ねると値の全体が表示されます。既定はオフで、再読み込みや区切り
  文字の変更をまたいで維持されます。
- **Excel 用にコピー** — タブ区切りテキスト。Excel や Google スプレッドシートにそのままセル貼り付け
  できます。
- **Markdown でコピー** — GitHub 形式の表。パイプはエスケープし、セル内改行は `<br>` に変換します。
- どちらのコピーも、**現在の絞り込み・ソート結果の全行**を対象とします（表示中のページだけでは
  ありません）。
- ツールバーで区切り文字を切り替えると、開き直さずに再解析します。

### ファイルの表示

エクスプローラーで `.csv` `.tsv` `.tab` ファイルを右クリックし、**CSV/TSV: 表として表示** を選び
ます。複数選択にも対応しており、それぞれ別タブで開きます。これらのファイルをテキストとして開いて
いるときは、エディタのタイトルバーのボタンからも実行できます。

**この拡張機能が既定のエディタになることはありません。** `priority: "option"` で登録しているため、
`.csv` や `.tsv` は通常どおりテキストエディタで開きます。表として見たいときだけ、右クリック
メニューまたは *エディターを再度開く* から明示的に選んでください。

## 設定

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| `csvTsvViewer.selectionDelimiter` | `auto` | 選択範囲・クリップボードの区切り文字。`auto` / `comma` / `tab` / `semicolon` / `pipe` / `space` / `whitespace`。 |
| `csvTsvViewer.hasHeader` | `true` | 最初の行をヘッダ行として扱う。 |
| `csvTsvViewer.pageSize` | `200` | 1ページに表示する行数。 |
| `csvTsvViewer.encoding` | `auto` | ファイルの文字エンコーディング。`auto`（BOM → UTF-8 → Shift_JIS の順に判定）/ `utf8` / `shift_jis`。 |
| `csvTsvViewer.followSelection` | `true` | エディタの選択範囲が変わったらプレビューを更新する。 |
| `csvTsvViewer.maxRows` | `100000` | 表示する最大行数。超過分は警告を出して切り捨てます。 |
| `csvTsvViewer.language` | `auto` | UI の表示言語。`auto` / `en` / `ja`。 |

## 開発

```bash
npm install
npm run compile      # 型チェック + バンドル
npm run watch        # 変更を監視して再ビルド（F5 と併用）
npm test             # ユニットテスト
npm run package      # .vsix をプロジェクト直下に生成
npm run icon         # images/icon.svg から images/icon.png を再生成
```

`npm run package` は型チェックとビルドを行い、`csv-tsv-viewer-<version>.vsix` をプロジェクト直下に
出力します。Marketplace への公開は手動で行うため、CI に公開用トークンは保存していません。

<kbd>F5</kbd> で拡張機能ホストが起動します。

- **拡張機能ホスト**（`src/`）— esbuild で `dist/extension.js` にバンドル（CommonJS、Node 18）。
- **Webview**（`src/webview/`）— `dist/webview/main.js`（IIFE、ES2020）と `main.css` にバンドル。
- **型チェック**は TypeScript 7（`tsc --noEmit`）が担当し、出力はすべて esbuild が行います。
